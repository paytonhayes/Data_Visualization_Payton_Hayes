## Source Note
The “Final_Balanced_Autoimmune_Data_Set.csv” version of the Comprehensive Autoimmune Disorder Dataset (Ragheb, 2024) was used in this analysis. Originally, there were 12500 patients included in the data set. However, in “Final_Balanced_Autoimmune_Data_Set.csv”, there were significantly fewer unique participant IDs. After removing duplicate IDs from the source file, there were only 643 observations left. As a result, the visualizations and generalizations drawn from the data set “Final_Balanced_Autoimmune_Data_Set.csv” may not be identical to those drawn from the file containing the original 12500 participants.
